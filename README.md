# 🚀 Neon Void: Cyberpunk Rogue Shooter

A fast-paced, standalone HTML5 Canvas arcade space shooter crafted with modern vanilla JavaScript. Features procedural sound synthesis, realistic particle explosions, dynamic camera shake, and progressive boss encounters.

## ⚡ Key Features
- **Zero Asset Dependencies:** Runs completely standalone without loading external images or `.mp3` files.
- **Procedural Audio Synthesizer:** Real-time SFX (lasers, impacts, power-ups) built directly on the **Web Audio API**.
- **Particle System & Screenshake:** Smooth physics-based debris, thruster exhaust, and screen-shake impulse dynamics.
- **Smart Enemy AI:** 
  - **Chasers:** Swarm-based direct engagement.
  - **Snipers:** Mid-range projectile shooters.
  - **Boss Battles:** Giant encounters appearing every 5 waves.
- **Power-Up System:** Energy Shields, Triple Blasters, and Health Nanobots.
- **Object-Oriented Architecture (OOP):** Modular, clean, and extensible code structure.
